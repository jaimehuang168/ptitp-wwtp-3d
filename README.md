# PTITP 污水處理廠 3D 互動模型 · Modelo 3D interactivo de la PTE PTITP

**🌐 線上瀏覽 / Ver en línea：https://jaimehuang168.github.io/ptitp-wwtp-3d/**

台巴智慧科技園區（PTITP，Minga Guazú, Paraguay）污水處理廠（MBBR 400 m³/d）的 3D 互動學習與查詢工具。點選槽體或設備即可查看功能說明、規格、電力資料，並直接開啟對應的操作手冊、P&ID、電氣圖與設備型錄。介面支援中文／Español／雙語切換。

Herramienta interactiva 3D de aprendizaje y consulta de la Planta de Tratamiento de Efluentes (MBBR 400 m³/d) del Parque Tecnológico Inteligente Taiwán-Paraguay (PTITP, Minga Guazú). Haga clic en un tanque o equipo para ver su función, especificaciones y datos eléctricos, y abrir directamente el manual de usuario, el P&ID, los planos eléctricos y los catálogos. Interfaz en 中文 / Español / bilingüe.
